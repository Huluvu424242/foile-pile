# Einführung in Unternehmens-PKI

Diese `.sld` Datei ist ein ZIP-basierter SLD-Foliensatz.

Enthalten sind:

* `slides.json`
* sichtbare Foliendateien unter `slides/`
* SSML-Audiotexte unter `audio/`
* SVG-Grafiken unter `assets/`
* zusätzliche Wiki-Quellen unter `wiki-source/`

Die Slideshow erklärt Zertifikate, PKI, Server-Zertifikate, Client-Zertifikate, mTLS und Firmenproxy/TLS-Inspection anhand eines Selenium-Docker-Kubernetes-Beispiels.
