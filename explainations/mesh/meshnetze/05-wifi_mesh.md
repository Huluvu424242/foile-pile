# WIFI Mesh

## 1. Ziel
Flächendeckendes WLAN mit nahtlosem Roaming und hoher Datenrate.

## 2. Devices
- Access Points (Mesh Nodes)
- Controller (optional)
- Router/Gateway

## 3. Funktionsweise
Knoten verbinden sich drahtlos untereinander und leiten Daten weiter.

## 4. Technische Daten
- Reichweite: 20–50 m indoor
- Durchsatz: bis >1 Gbit/s
- Limits: Interferenzen, Backhaul-Verlust

## 5. Einsatzzwecke
- Zuhause
- Büros
- Campus-Netze
