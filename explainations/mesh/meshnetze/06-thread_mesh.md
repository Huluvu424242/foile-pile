# Thread Mesh

## 1. Ziel
Energieeffizientes IoT-Netzwerk.

## 2. Devices
- Border Router
- Router Nodes
- End Devices

## 3. Funktionsweise
IPv6-basiertes Mesh mit selbstheilendem Routing.

## 4. Technische Daten
- Reichweite: 10–30 m
- Datenrate: ~250 kbit/s
- Limits: geringe Bandbreite

## 5. Einsatzzwecke
- Smart Home
- Sensorik
