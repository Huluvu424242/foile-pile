# LoRa Mesh

## 1. Ziel
Langstrecken-Kommunikation mit geringem Energieverbrauch.

## 2. Devices
- Nodes
- Gateways

## 3. Funktionsweise
Weitreichende Funkverbindungen, oft mit Store-and-Forward.

## 4. Technische Daten
- Reichweite: mehrere km bis >10 km
- Datenrate: sehr gering (0.3–50 kbit/s)
- Limits: Duty Cycle, geringe Bandbreite

## 5. Einsatzzwecke
- Sensor-Netze
- Off-Grid Kommunikation
