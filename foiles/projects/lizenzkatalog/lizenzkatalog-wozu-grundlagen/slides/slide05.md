# Warum „einfach MIT“ oder proprietär nicht reicht

Die eigene Lizenz regelt nur das, was man selbst lizenzieren darf.

- fremder Code bleibt fremder Code
- Lizenz-Header sind starke Warnsignale
- Pflichten können weiterwirken

**GPL-Header im Quelltext?** Dann ist „wir nehmen MIT“ keine saubere Antwort.
