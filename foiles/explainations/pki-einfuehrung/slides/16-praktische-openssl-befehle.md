# Praktische OpenSSL Befehle

![OpenSSL Befehle](assets/08-openssl.svg)

Typische Prüfungen:

* Zertifikat anzeigen
* Private Key prüfen
* P12/PFX Container inspizieren
* Public Keys vergleichen
* Zertifikatsketten analysieren

OpenSSL prüft den tatsächlichen Inhalt einer Datei und nicht ihren Dateinamen.
