# Zigbee Mesh

## 1. Ziel
Zuverlässige Kommunikation für IoT-Geräte.

## 2. Devices
- Coordinator
- Router
- End Devices

## 3. Funktionsweise
Hierarchisches Mesh mit Coordinator als zentralem Einstiegspunkt.

## 4. Technische Daten
- Reichweite: 10–100 m
- Datenrate: 250 kbit/s
- Limits: begrenzte Netzgröße

## 5. Einsatzzwecke
- Smart Home
- Industrieautomation
