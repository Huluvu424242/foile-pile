# Grundprinzip eines Mesh Netzes

Ein Mesh-Netz bedeutet:

- Jeder Knoten (Node) kann Daten weiterleiten
- Es gibt keinen zentralen Router
- Daten finden dynamisch ihren Weg (Routing über Nachbarn)

👉 Ergebnis: robust, dezentral, oft unabhängig vom Internet

Bekannte Vertreter der Mesh Technologie:
* WIFI Mesh
* Thread Mesh
* Zigbee Mesh 
* Bluethooth / Smartphone Mesh
* LoRa Mesh / Low-Power Mesh
* Amateurfunk Mesh (HAM Mesh)
* Pager Netze (Broeadcast, kein echtes Mesh)
* Spezialformen (Forschung & Militär)
