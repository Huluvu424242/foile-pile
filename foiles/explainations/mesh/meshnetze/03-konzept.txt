
Die Mesch-Netze basieren auf einer dynamisch wechselnden Zahl an Knoten und Verbindungen.

Sie sind charakterisiert durch folgende Eigenschaften:

Erstens: Jeder Knoten kann Daten weiterleiten.
Zweitens: Es gibt im Netz keinen zentralen Router
Drittens: Das Routing der Daten erfolgt dynamisch und die Routen können schnell wechseln.

Bekannte Vertreter der Mesh Technologie:

WIFI Mesh
Thread Mesh
Zigbee Mesh
Bluethooth / Smartphone Mesh
LoRa Mesh / Low-Power Mesh
Amateurfunk Mesh (HAM Mesh)
Pager Netze (Broeadcast, kein echtes Mesh)
Spezialformen (Forschung & Militär)
